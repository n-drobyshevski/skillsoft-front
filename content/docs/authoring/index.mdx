# Создание контента

Этот раздел посвящен созданию качественных материалов для оценки: компетенций, поведенческих индикаторов и вопросов.

## Иерархия контента

Вся система оценки построена на трехуровневой иерархии:

<Diagram>
```
         КОМПЕТЕНЦИЯ
         (что оцениваем)
              |
    +---------+---------+
    |         |         |
ИНДИКАТОР ИНДИКАТОР ИНДИКАТОР
(как проявляется)
    |
+---+---+
|   |   |
Q   Q   Q
(как измеряем)
```
</Diagram>

### Пример иерархии

| Уровень | Пример | Описание |
|---------|--------|----------|
| **Компетенция** | Коммуникация | Способность эффективно обмениваться информацией |
| **Индикатор** | Адаптирует стиль общения | Конкретное наблюдаемое поведение |
| **Вопрос** | "Я изменяю манеру речи в зависимости от собеседника" | Измерительный инструмент |

## Роли контента

### Компетенция

**Что это:** Измеряемый навык или способность, состоящий из нескольких поведенческих проявлений.

**Характеристики:**
- Абстрактный уровень
- Содержит 3-8 индикаторов
- Привязана к международным стандартам
- Имеет категорию и уровень сложности

**Подробнее:** [Как писать компетенции](/docs/authoring/competencies)

---

### Поведенческий индикатор

**Что это:** Конкретное, наблюдаемое поведение, демонстрирующее владение компетенцией.

**Характеристики:**
- Конкретный, наблюдаемый
- Имеет вес (важность) в рамках компетенции
- Содержит примеры и контрпримеры
- Связан с 2+ вопросами

**Подробнее:** [Поведенческие индикаторы](/docs/authoring/indicators)

---

### Вопрос оценки

**Что это:** Инструмент измерения, позволяющий оценить проявление индикатора.

**Характеристики:**
- Три типа: Лайкерт, ситуационные, множественный выбор
- Имеет психометрические свойства
- Проходит валидацию качества

**Подробнее:** [Написание вопросов](/docs/authoring/questions)

## Процесс создания контента

<Steps>

### Определите компетенцию

Начните с верхнего уровня - какой навык вы хотите оценивать?

- Изучите существующие компетенции в системе
- Проверьте, нет ли похожей компетенции
- Определите категорию и целевую аудиторию

### Разработайте индикаторы

Для каждой компетенции определите 3-8 наблюдаемых поведений:

- Каждый индикатор должен быть конкретным
- Индикаторы должны покрывать разные аспекты компетенции
- Назначьте веса в соответствии с важностью

### Создайте вопросы

Для каждого индикатора напишите минимум 2 вопроса:

- Используйте разные типы вопросов
- Варьируйте уровень сложности
- Следуйте рекомендациям по написанию

### Проведите ревью

Перед публикацией контент должен пройти проверку:

- Экспертная оценка содержания
- Проверка на соответствие стандартам
- Пилотное тестирование (опционально)

### Мониторьте качество

После публикации отслеживайте психометрические показатели:

- Индекс сложности
- Индекс дискриминации
- Альфа Кронбаха компетенции

</Steps>

## Стандарты качества

### Требования к компетенции

| Критерий | Требование |
|----------|------------|
| Название | Уникальное, ясное |
| Описание | 50-1000 символов |
| Индикаторы | 3-8 штук |
| Стандарты | Минимум одна привязка (ESCO, O*NET, Big Five) |
| Сумма весов | Ровно 1.0 (100%) |

### Требования к индикатору

| Критерий | Требование |
|----------|------------|
| Название | До 150 символов |
| Описание | 50-500 символов |
| Примеры | 3-5 штук |
| Контрпримеры | 2-3 штуки |
| Вопросы | Минимум 2 |

### Требования к вопросу

| Критерий | Требование |
|----------|------------|
| Текст | Ясный, однозначный |
| Варианты ответов | Корректно оформлены |
| Индекс дискриминации | Целевой > 0.30 |
| Индекс сложности | В диапазоне 0.2-0.9 |

## Жизненный цикл контента

### Статусы компетенций

```
ЧЕРНОВИК → НА ПРОВЕРКЕ → ОДОБРЕНА (или ОТКЛОНЕНА)
                              |
                              v
                         НА ДОРАБОТКЕ → НА ПРОВЕРКЕ
                              |
                              v
                         АРХИВИРОВАНА
```

| Статус | Описание | Доступные действия |
|--------|----------|-------------------|
| **Черновик** | Работа в процессе | Редактирование, отправка на проверку |
| **На проверке** | Ожидает одобрения | Только просмотр |
| **Одобрена** | Активна, используется в тестах | Создание версии для доработки |
| **Отклонена** | Не прошла проверку | Возврат в черновик |
| **На доработке** | Обновление одобренной версии | Редактирование |
| **Архивирована** | Не используется | Восстановление (админ) |

<Callout type="info">
Только **одобренные** компетенции доступны для использования в тестах.
</Callout>

## Международные стандарты

### Зачем нужна привязка к стандартам?

Привязка к международным стандартам обеспечивает:

1. **Научную обоснованность** - компетенции основаны на исследованиях
2. **Сравнимость** - результаты можно сравнивать с внешними данными
3. **Валидность** - содержание соответствует признанным моделям

### Три стандарта в SkillSoft

| Стандарт | Описание | Использование |
|----------|----------|---------------|
| **ESCO** | Европейская классификация навыков | Структура компетенций |
| **O*NET** | Американская база профессий | Job Fit оценка |
| **Big Five** | Пятифакторная модель личности | Личностный профиль |

<Callout type="tip">
При создании компетенции рекомендуется привязать ее хотя бы к одному стандарту. Это повышает валидность оценки.
</Callout>

## Советы для начинающих

### Начните с изучения

Прежде чем создавать собственный контент:

1. Изучите существующие компетенции в системе
2. Посмотрите примеры качественных индикаторов
3. Проанализируйте структуру хороших вопросов

### Используйте шаблоны

Система предоставляет шаблоны для:

- Формулировок компетенций
- Структуры индикаторов
- Форматов вопросов

### Получайте обратную связь

- Показывайте черновики коллегам
- Учитывайте замечания рецензентов
- Анализируйте психометрические показатели после публикации

<Callout type="note">
Создание качественного контента - итеративный процесс. Не ожидайте идеального результата с первой попытки.
</Callout>
