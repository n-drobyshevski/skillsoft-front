# Быстрый старт

Это краткое руководство познакомит вас с основными концепциями платформы SkillSoft и поможет начать работу.

## Что такое SkillSoft?

SkillSoft - это платформа для оценки soft skills (гибких навыков) сотрудников. В отличие от hard skills (технических навыков), soft skills включают:

- Коммуникацию и взаимодействие
- Лидерство и влияние
- Критическое мышление
- Эмоциональный интеллект
- Адаптивность и гибкость

<Callout type="info">
Soft skills - это навыки, которые определяют, **как** человек работает, а не **что** он умеет делать технически.
</Callout>

## Ключевые концепции за 5 минут

### Иерархия оценки

Система SkillSoft построена на трехуровневой модели:

<Diagram>
```
Компетенция (что оцениваем)
    |
    +-- Поведенческий индикатор (как проявляется)
            |
            +-- Вопрос оценки (как измеряем)
```
</Diagram>

**Пример:**

| Уровень | Пример |
|---------|--------|
| Компетенция | Коммуникация |
| Индикатор | Адаптирует стиль общения под аудиторию |
| Вопрос | "Я изменяю способ объяснения в зависимости от уровня знаний собеседника" |

### Три типа тестов

SkillSoft поддерживает три сценария оценки:

| Тип теста | Назначение | Когда использовать |
|-----------|------------|-------------------|
| **Паспорт компетенций** (Overview) | Универсальный профиль навыков | Для всех сотрудников, развитие |
| **Соответствие должности** (Job Fit) | Оценка под конкретную позицию | Подбор, продвижение |
| **Командная совместимость** (Team Fit) | Анализ вписывания в команду | Формирование команд |

### Три типа вопросов

Для измерения компетенций используются три формата вопросов:

| Тип | Доля | Пример |
|-----|------|--------|
| **Шкала Лайкерта** | 70% | "Согласен / Не согласен" |
| **Ситуационные суждения** | 25% | "Что бы вы сделали в этой ситуации?" |
| **Множественный выбор** | 5% | "Какой фактор наиболее важен?" |

## Роли в системе

В SkillSoft существуют две основные роли:

### HR-администратор

Что вы можете делать:
- Создавать и редактировать компетенции
- Добавлять поведенческие индикаторы
- Писать и редактировать вопросы оценки
- Создавать шаблоны тестов
- Просматривать результаты сотрудников
- Мониторить качество вопросов

### Сотрудник

Что могут делать сотрудники:
- Проходить назначенные тесты
- Просматривать свои результаты
- Видеть рекомендации по развитию

<Callout type="tip">
Используйте режим "Тест-драйв" для предварительного просмотра тестов перед их назначением сотрудникам. Это поможет убедиться, что все работает корректно.
</Callout>

## Основные термины

Вот минимальный набор терминов, которые вам понадобятся:

| Термин | Значение |
|--------|----------|
| **Компетенция** | Измеряемый навык или способность |
| **Индикатор** | Конкретное поведение, демонстрирующее компетенцию |
| **Шаблон теста** | Конфигурация теста (какие компетенции оценивать) |
| **Сессия** | Конкретное прохождение теста сотрудником |
| **Результат** | Итоги прохождения теста |

<Callout type="note">
Полный список терминов с подробными определениями доступен в [Глоссарии](/docs/glossary).
</Callout>
