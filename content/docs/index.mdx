# Документация SkillSoft

Добро пожаловать в документацию платформы SkillSoft. Здесь вы найдете все необходимое для эффективной работы с системой оценки soft skills.

## Что такое SkillSoft?

SkillSoft - это современная платформа для оценки и развития soft skills сотрудников. Система сочетает научно обоснованные методики психометрии с удобным интерфейсом, позволяя HR-специалистам:

- Создавать и проводить профессиональные оценочные тесты
- Оценивать соответствие кандидатов требованиям должности
- Анализировать командную совместимость
- Формировать индивидуальные планы развития
