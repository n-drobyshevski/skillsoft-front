# Система оценивания

Узнайте, как SkillSoft рассчитывает результаты тестирования и что означают итоговые баллы.

## Общий принцип

Система оценивания работает по принципу "снизу вверх":

<Diagram>
```
Ответ на вопрос
      |
      v (нормализация)
Нормализованный балл (0-100%)
      |
      v (агрегация)
Балл индикатора
      |
      v (взвешивание)
Балл компетенции
      |
      v (усреднение)
Общий балл теста
```
</Diagram>

## Шаг 1: Нормализация ответов

### Зачем нужна нормализация?

Разные типы вопросов используют разные шкалы ответов:

| Тип вопроса | Исходная шкала | Пример |
|-------------|----------------|--------|
| Шкала Лайкерта | 1-5 | "Согласен" = 4 |
| Ситуационные | 0-4 | "Оптимальный" = 4 |
| Множественный выбор | 0 или 1 | Правильно = 1 |

Чтобы корректно сравнивать и складывать баллы, все они приводятся к единой шкале **от 0 до 1** (или от 0% до 100%).

### Как это работает

<Callout type="info">
**Простое объяснение:** Мы переводим все ответы в проценты от максимально возможного балла.
</Callout>

**Шкала Лайкерта (1-5):**

```
Нормализованный балл = (Ответ - 1) / 4

Примеры:
  Ответ 1 (Совершенно не согласен) → 0%
  Ответ 2 (Не согласен)            → 25%
  Ответ 3 (Нейтрально)             → 50%
  Ответ 4 (Согласен)               → 75%
  Ответ 5 (Полностью согласен)     → 100%
```

**Ситуационные суждения:**

```
Нормализованный балл = Балл выбранного варианта / Максимальный балл

Пример (шкала 0-4):
  Выбран вариант с баллом 3 → 3/4 = 75%
```

**Множественный выбор:**

```
Правильный ответ → 100%
Неправильный ответ → 0%
```

## Шаг 2: Агрегация по уровням

### Уровень 1: Вопросы в Индикатор

Баллы всех вопросов одного индикатора усредняются:

```
Балл индикатора = Среднее (баллы всех вопросов индикатора)
```

**Пример:**

| Вопрос | Нормализованный балл |
|--------|---------------------|
| Вопрос 1 | 75% |
| Вопрос 2 | 100% |
| Вопрос 3 | 50% |
| **Итого индикатор** | **(75 + 100 + 50) / 3 = 75%** |

### Уровень 2: Индикаторы в Компетенцию

Баллы индикаторов складываются с учетом их **весов**:

```
Балл компетенции = Сумма (балл индикатора * вес индикатора)
```

<Callout type="note">
**Вес индикатора** показывает, насколько важен этот индикатор для компетенции. Сумма весов всех индикаторов компетенции всегда равна 1 (100%).
</Callout>

**Пример компетенции "Коммуникация":**

| Индикатор | Балл | Вес | Вклад |
|-----------|------|-----|-------|
| Активное слушание | 75% | 0.40 | 30% |
| Ясное изложение | 80% | 0.35 | 28% |
| Невербальные сигналы | 60% | 0.25 | 15% |
| **Итого** | | **1.00** | **73%** |

### Уровень 3: Компетенции в Общий балл

Общий балл теста - это среднее всех компетенций:

```
Общий балл = Среднее (баллы всех компетенций)
```

**Пример:**

| Компетенция | Балл |
|-------------|------|
| Коммуникация | 73% |
| Критическое мышление | 85% |
| Адаптивность | 62% |
| **Общий балл** | **(73 + 85 + 62) / 3 = 73%** |

## Особенности разных типов тестов

### Паспорт компетенций (Overview)

- Используется стандартная схема оценивания
- Нет порога прохождения
- Результат - профиль баллов по компетенциям
- Нейтральная интерпретация (нет "хорошо/плохо")

### Соответствие должности (Job Fit)

**Дополнительные особенности:**

1. **Взвешивание по стандартам:** Компетенции, привязанные к международным стандартам, получают повышенный приоритет:

| Стандарт | Коэффициент | Описание |
|----------|-------------|----------|
| O*NET | 1.2 | Компетенции с кодом O*NET SOC |
| ESCO | 1.15 | Компетенции с URI ESCO |
| Big Five | 1.1 | Компетенции с привязкой к личностной черте |

<Callout type="note">
Коэффициенты складываются мультипликативно. Если компетенция привязана и к O*NET, и к ESCO, её суммарный вес будет 1.2 × 1.15 = 1.38. Максимальный итоговый множитель ограничен **3.0** для предотвращения перекосов.
</Callout>

2. **Динамический порог прохождения:**

```
Порог = 50% + (Строгость / 100) * 30%

Примеры:
  Строгость 0%   → Порог 50%
  Строгость 50%  → Порог 65%
  Строгость 100% → Порог 80%
```

3. **Gap-анализ:** Система показывает разрыв между результатом и требованиями должности

### Командная совместимость (Team Fit)

**Дополнительные особенности:**

1. **Классификация вклада:**

| Балл | Классификация | Значение |
|------|---------------|----------|
| 75%+ | Насыщение | Кандидат силен там, где команда уже сильна |
| 50-74% | Разнообразие | Кандидат добавляет ценность |
| Менее 50% | Пробел | Зона развития кандидата |

2. **Командный мультипликатор:**
   - Бонус +10% если кандидат добавляет разнообразие (срабатывает при доле разнообразия > 40%)
   - Штраф -10% если кандидат дублирует уже сильные области (срабатывает при доле насыщения > 80%)

3. **Критерий ценности:** Балл 60%+ И разнообразие 30%+

4. **Расширенные параметры:**

| Параметр | Значение | Описание |
|----------|----------|----------|
| Порог малой команды | 5 человек | Если в команде менее 5 участников, пороги корректируются |
| Коррекция малой команды | ±10% | Пороги разнообразия и насыщения смягчаются для малых команд |
| Штраф за критический пробел | -10% | Дополнительный штраф, если у кандидата критический разрыв в ключевой компетенции |

<Callout type="info">
Для малых команд (менее 5 человек) система автоматически снижает пороги, так как статистическая база профиля команды менее надёжна.
</Callout>

## Интерпретация результатов

### Шкала интерпретации

| Балл | Уровень | Интерпретация |
|------|---------|---------------|
| 90-100% | Экспертный | Выдающееся владение |
| 75-89% | Продвинутый | Уверенное владение |
| 60-74% | Уверенный | Стабильное владение |
| 45-59% | Развивающийся | Базовое владение, есть потенциал |
| 0-44% | Начальный | Требуется значительное развитие |

Для Паспорта компетенций система дополнительно рассчитывает проекцию на пять базовых черт личности:

| Черта | Описание |
|-------|----------|
| Открытость | Любознательность, креативность |
| Добросовестность | Организованность, ответственность |
| Экстраверсия | Общительность, энергичность |

| Эмоциональная стабильность | Устойчивость, спокойствие |

<Callout type="info">
Проекция на Big Five помогает увидеть личностный профиль через призму профессиональных компетенций.

## Перцентиль

### Что такое перцентиль?

Перцентиль показывает, какой процент других участников набрал меньше баллов.

**Пример:** Перцентиль 75 означает, что результат лучше, чем у 75% других участников.

### Как рассчитывается

```
Перцентиль = (Количество с меньшим баллом / Общее количество) * 100
```

<Callout type="note">
Перцентиль рассчитывается отдельно для каждого шаблона теста, поэтому сравнение идет с людьми, прошедшими тот же тест.
</Callout>

## Пропущенные вопросы

### Как учитываются пропуски

| Тип пропуска | Обработка |
|--------------|-----------|
| Пропущен (нет ответа) | Не учитывается в расчете |
| Истекло время | Засчитывается как 0 |

<Callout type="warning">
Большое количество пропусков может исказить результат, так как база для расчета среднего уменьшается.
</Callout>

## Пример полного расчета

Рассмотрим расчет для теста из 2 компетенций:

### Исходные данные

**Компетенция "Коммуникация":**
- Индикатор 1 (вес 0.6): вопросы с баллами 4, 5, 3 (из 5)
- Индикатор 2 (вес 0.4): вопросы с баллами 4, 4 (из 5)

**Компетенция "Лидерство":**
- Индикатор 1 (вес 0.5): вопросы с баллами 3, 4, 3 (из 5)
- Индикатор 2 (вес 0.5): SJT с баллом 3 (из 4)

### Расчет

**Шаг 1: Нормализация**

```
Коммуникация, Индикатор 1:
  (4-1)/4=0.75, (5-1)/4=1.0, (3-1)/4=0.5 → среднее = 0.75

Коммуникация, Индикатор 2:
  (4-1)/4=0.75, (4-1)/4=0.75 → среднее = 0.75

Лидерство, Индикатор 1:
  (3-1)/4=0.5, (4-1)/4=0.75, (3-1)/4=0.5 → среднее = 0.58

Лидерство, Индикатор 2:
  3/4=0.75 → среднее = 0.75
```

**Шаг 2: Взвешивание индикаторов**

```
Коммуникация = 0.75*0.6 + 0.75*0.4 = 0.45 + 0.30 = 0.75 (75%)
Лидерство = 0.58*0.5 + 0.75*0.5 = 0.29 + 0.375 = 0.67 (67%)
```

**Шаг 3: Общий балл**

```
Общий балл = (75 + 67) / 2 = 71%
```

### Итоговый результат

| Показатель | Значение |
|------------|----------|
| Общий балл | 71% |
| Коммуникация | 75% |
| Лидерство | 67% |
| Уровень | Уверенный |

## Часто задаваемые вопросы

**Почему мой балл по компетенции отличается от среднего по вопросам?**

Из-за системы весов индикаторов. Если индикаторы имеют разные веса, простое среднее не даст точный результат.

**Влияет ли время ответа на балл?**

Нет, время влияет только на то, засчитается ли ответ. Если ответ дан в пределах лимита, время не влияет на балл.

**Как сравнивать результаты разных тестов?**

Напрямую сравнивать баллы разных тестов некорректно, так как они могут оценивать разные компетенции. Используйте перцентили для сравнения позиции участника относительно других.
